The optional `npm run test:release` fixtures are for deliberate release-tool changes, not an ordinary quality gate. Platform jobs install runtime/build dependencies, produce one package build and their native archive, then test installation, failed candidates, two sequential upgrades, rollback and removal using two previous published releases and the saved new archive. They do not repeat Python code checks or build artificial versions.

PRs finish after the platform builds. Quality contains no release planning. Main platform builds resolve their package version using the actual semantic-release engine, so packages and archives are built once with the version they will publish. A local build tag at the checked commit supplies that version and is not pushed by the build jobs. PRs and documentation-only main commits build their normal Git-derived development version. Public tagging, attestations and publication belong to the final release stage.

Final publication verifies both saved artifact receipts, source commits, versions and checksums. Only the two native installer bundles and SHA256SUMS are uploaded. Each bundle embeds its internal wheel and matching OS installer; no standalone Python wheel or source distribution is built for public download. GitHub provides its automatic source-code links separately. Publication regenerates the combined checksum file and attests the exact collected bytes. Semantic-release resolves the version again, and the official exec plugin rejects any version/source mismatch before publication. The maintained semantic-release action runs that pipeline; its GitHub plugin uploads those files without rebuilding. Main workflows are serialized, and a stale run safely publishes nothing when its source is behind main. Documentation-only commits do not publish.

Installer acceptance requires two prior published DisCuss bundles; failure to download or verify them fails the build. All privileged acceptance runs on disposable GitHub-hosted runners, without Discord credentials. Speech measurement is synthetic and reports observed accuracy/capacity limits; it does not establish production accuracy or real reboot qualification. There are no manual release-readiness switches.
